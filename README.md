## 1. HashMap / HashSet

### 核心觀念

記住以前出現過的資料，之後便能快速查找。

- `HashSet`：記錄某個值是否出現過。
- `HashMap`：記錄某個鍵所對應的索引、次數或其他資訊。

辨識訊號：查重、配對、統計次數、是否出現過、最早或最近出現的位置。

### 範例一：Two Sum

```text
nums = [2, 7, 11, 15], target = 9
輸出：[0, 1]
```

看到 `7` 時，計算目前需要的數字：

```text
9 - 7 = 2
```

再查詢 `2` 是否曾經出現。考點是建立「數字 → 索引」的對應。

### 範例二：判斷是否有重複元素

```text
nums = [1, 2, 3, 1]
輸出：true
```

使用 `HashSet` 記錄已經看過的數字；加入前若已存在，就找到重複值。

### 範例三：最長連續數字序列

```text
nums = [100, 4, 200, 1, 3, 2]
輸出：4
```

最長序列是 `[1, 2, 3, 4]`。使用 `HashSet` 快速判斷下一個整數是否存在。

## 2. 雙指標

### 核心觀念

用兩個位置一起移動，有方向地縮小搜尋範圍，避免所有元素兩兩比較。

辨識訊號：已排序陣列、兩數配對、左右比較、原地移除或合併元素。

### 範例一：已排序陣列的 Two Sum

```text
nums = [1, 2, 4, 6, 8], target = 10
輸出：[2, 8] 或 [4, 6]
```

- 總和太小：左指標向右移。
- 總和太大：右指標向左移。

### 範例二：判斷回文

```text
s = "racecar"
輸出：true
```

左右指標從字串兩端開始，逐步向中間比較。

### 範例三：盛最多水的容器

```text
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
輸出：49
```

左右指標形成容器，每次移動較矮的一邊，才可能找到更大的面積。

## 3. 滑動視窗

### 核心觀念

維護一段連續區間：右邊加入新元素，左邊移除舊元素。

辨識訊號：連續子陣列或子字串、最長或最短區間、固定長度區間。

### 範例一：固定長度子陣列最大總和

```text
nums = [2, 1, 5, 1, 3, 2], windowSize = 3
輸出：9
```

因為長度為 `3` 的區間 `[5, 1, 3]`，總和為 `9`。

### 範例二：無重複字元的最長子字串

```text
s = "abcabcbb"
輸出：3
```

答案可以是 `"abc"`。視窗出現重複字元時，移動左邊界直到重新符合條件。

### 範例三：總和至少為 K 的最短子陣列

```text
nums = [2, 3, 1, 2, 4, 3], k = 7
輸出：2
```

答案是 `[4, 3]`。這種普通滑動視窗依賴元素為正數，或題目條件具有單調性。

> 若區間總和題可能包含負數，普通滑動視窗通常會失效，應考慮前綴和。

## 4. 前綴和

### 核心觀念

先記錄從開頭累加到每個位置的總和。一段連續區間的總和，等於兩個前綴和相減。

```text
區間 left～right 的總和
= prefix[right + 1] - prefix[left]
```

辨識訊號：連續區間總和、多次區間查詢、陣列包含負數、總和等於 `k`。

### 範例一：區間總和查詢

```text
nums = [2, 3, 1, 4]
查詢索引 1～3
輸出：8
```

要求的區間是 `[3, 1, 4]`，總和為 `8`。

### 範例二：總和等於 K 的子陣列數量

```text
nums = [1, 1, 1], k = 2
輸出：2
```

使用「前綴和 + `HashMap<前綴和, 出現次數>`」。

### 範例三：總和等於 K 的最長子陣列

```text
nums = [1, -1, 5, -2, 3], k = 3
輸出：4
```

最長區間是 `[1, -1, 5, -2]`。使用「前綴和 + `HashMap<前綴和, 最早索引>`」。

## 5. 二分搜尋

### 核心觀念

利用排序或單調分界，每次排除一半不可能的答案。

辨識訊號：資料已排序、要求 `O(log n)`、第一個或最後一個符合條件的位置、最小可行答案。

### 範例一：在排序陣列中找數字

```text
nums = [1, 3, 5, 7, 9], target = 7
輸出：3
```

比較中間值與目標，再保留可能包含答案的一半。

### 範例二：找第一個大於等於 Target 的位置

```text
nums = [1, 3, 3, 5, 8], target = 3
輸出：1
```

這是在找二分搜尋的左邊界。

### 範例三：最小吃香蕉速度

```text
piles = [3, 6, 7, 11], hours = 8
輸出：4
```

這題不是對陣列索引二分，而是對「可能的速度」二分：

- 速度太慢：增加速度。
- 速度足夠：嘗試更小的速度。

這類技巧稱為「對答案二分搜尋」。

## 6. 排序與區間

### 核心觀念

排序後，原本分散的相關元素會靠在一起，很多全局關係便能轉成相鄰比較。

辨識訊號：區間重疊、合併區間、排程、最小差距、活動選擇。

### 範例一：合併區間

```text
intervals = [[1,3], [2,6], [8,10]]
輸出：[[1,6], [8,10]]
```

先按照開始位置排序，再判斷下一段是否與目前區間重疊。

### 範例二：插入新區間

```text
intervals = [[1,3], [6,9]]
newInterval = [2,5]
輸出：[[1,5], [6,9]]
```

### 範例三：刪除最少區間，使其互不重疊

```text
intervals = [[1,2], [2,3], [3,4], [1,3]]
輸出：1
```

通常按照結束位置排序，再搭配貪心選擇。

## 7. Stack

### 核心觀念

Stack 是後進先出結構，適合處理最近開始但尚未完成的事情。

辨識訊號：括號配對、巢狀結構、撤銷、運算式、路徑返回。

### 範例一：有效括號

```text
s = "([]{})"
輸出：true
```

左括號進棧，右括號必須與棧頂的左括號配對。

### 範例二：計算後綴表達式

```text
tokens = ["2", "1", "+", "3", "*"]
輸出：9
```

計算過程為 `(2 + 1) × 3 = 9`。

### 範例三：簡化檔案路徑

```text
path = "/home/user/../docs"
輸出："/home/docs"
```

遇到 `..` 時，從 Stack 彈出上一層目錄。

## 8. 單調棧與單調隊列

### 核心觀念

保持資料單調遞增或遞減，並淘汰已不可能成為答案的舊元素。

辨識訊號：下一個更大或更小元素、還要等待多久、滑動視窗最大或最小值。

### 範例一：每日溫度

```text
temperatures = [73,74,75,71,69,72,76,73]
輸出：[1,1,4,2,1,1,0,0]
```

對每一天找右邊第一個溫度更高的位置。

### 範例二：下一個更大元素

```text
nums = [2, 1, 4, 3]
輸出：[4, 4, -1, -1]
```

單調棧保存尚未找到下一個更大值的位置。

### 範例三：滑動視窗最大值

```text
nums = [1,3,-1,-3,5,3,6,7], k = 3
輸出：[3,3,5,5,6,7]
```

使用單調隊列維護目前視窗中的最大值。

## 9. Heap / PriorityQueue

### 核心觀念

不必將所有元素完整排序，也能快速取得目前最小或最大的元素。

辨識訊號：前 `K` 大或小、動態最大最小值、合併多個排序序列、排程。

### 範例一：第 K 大元素

```text
nums = [3,2,1,5,6,4], k = 2
輸出：5
```

維護大小為 `k` 的最小 Heap，最後堆頂就是第 `k` 大元素。

### 範例二：出現頻率最高的 K 個元素

```text
nums = [1,1,1,2,2,3], k = 2
輸出：[1,2]
```

搭配 `HashMap` 統計次數，再用 Heap 選出前 `k` 名。

### 範例三：合併 K 個已排序鏈表

```text
[1,4,5]
[1,3,4]
[2,6]
```

每次從 Heap 取出所有鏈表目前最小的節點。

## 10. 快慢指標

### 核心觀念

利用兩個指標的速度或距離不同，找出中點、循環或特定距離的位置。

辨識訊號：鏈表中點、鏈表環、循環入口、倒數位置。

### 範例一：找鏈表中點

```text
1 → 2 → 3 → 4 → 5
輸出：3
```

慢指標每次走一步，快指標每次走兩步。

### 範例二：判斷鏈表是否有環

```text
1 → 2 → 3 → 4
        ↑     ↓
        ← ← ←
```

如果有環，快指標最後會追上慢指標。

### 範例三：找重複數字

```text
nums = [1,3,4,2,2]
輸出：2
```

可以把陣列視為指向關係，再使用 Floyd Cycle Detection。

## 11. 遞迴與回溯

### 核心觀念

做出一個選擇、繼續探索、撤銷選擇，再嘗試另一條路。

辨識訊號：所有排列、組合、子集合、所有可能路徑、棋盤放置。

### 範例一：所有子集合

```text
nums = [1,2]
輸出：[]、[1]、[2]、[1,2]
```

每個元素都有「選擇」和「不選擇」兩種決定。

### 範例二：所有排列

```text
nums = [1,2,3]
輸出：[1,2,3]、[1,3,2]、[2,1,3]……
```

每一層選擇一個尚未使用的元素。

### 範例三：組合總和

```text
candidates = [2,3,6,7], target = 7
輸出：[2,2,3]、[7]
```

選擇數字後繼續探索；總和超過目標時返回。

## 12. Tree DFS / BFS

### 核心觀念

- DFS：先沿著一條分支走到底，適合子樹、深度和路徑問題。
- BFS：一層一層走，適合層級和距離問題。

### 範例一：二元樹最大深度

```text
       3
      / \
     9  20
       /  \
      15   7

輸出：3
```

使用 DFS：目前深度等於 `1 + 左右子樹最大深度`。

### 範例二：路徑總和

判斷是否存在一條從根節點到葉節點的路徑，使節點總和等於目標值。這類題適合 DFS。

### 範例三：層序遍歷

```text
       3
      / \
     9  20
       /  \
      15   7

輸出：[[3], [9,20], [15,7]]
```

使用 BFS 一層一層處理。

## 13. Graph DFS / BFS

### 核心觀念

走訪節點之間的關係。Graph 可能存在環，所以通常必須使用 `visited` 防止重複拜訪。

辨識訊號：城市與道路、朋友關係、網路連通、地圖格子、最少步數。

### 範例一：島嶼數量

```text
1 1 0
1 0 0
0 0 1

輸出：2
```

每找到一塊尚未拜訪的陸地，就用 DFS 或 BFS 走完整座島。

### 範例二：判斷是否存在路徑

```text
edges = [[0,1], [1,2], [2,3]]
start = 0, end = 3
輸出：true
```

### 範例三：二進位矩陣最短路徑

從左上角走到右下角，`0` 可以走，`1` 不可以走。每一步距離相同，因此優先使用 BFS。

## 14. 拓撲排序

### 核心觀念

每次先處理目前沒有未完成前置依賴的項目。入度為 `0` 表示現在可以執行。

辨識訊號：課程先修、工作依賴、編譯順序、判斷依賴是否成環。

### 範例一：能否完成所有課程

```text
課程 1 需要先完成課程 0
prerequisites = [[1,0]]
輸出：true
```

如果依賴形成環，就無法完成所有課程。

### 範例二：輸出課程修習順序

```text
依賴：0 → 1、0 → 2、1 → 3、2 → 3
可能輸出：[0,1,2,3]
```

### 範例三：推導未知字母順序

給定已按照某種外星字典順序排列的單字，推導字母之間的先後關係。這是「建立依賴圖 + 拓撲排序」。

## 15. 並查集

### 核心觀念

快速合併群組，並判斷兩個元素是否屬於同一群。

主要操作：

- `find(x)`：找到 `x` 所屬群組的代表。
- `union(a, b)`：合併 `a` 和 `b` 的群組。

### 範例一：朋友圈／省份數量

```text
A 認識 B
B 認識 C
D 單獨一組

輸出：2 組
```

### 範例二：找多餘的連線

```text
edges = [[1,2], [1,3], [2,3]]
輸出：[2,3]
```

加入 `[2,3]` 前，`2` 和 `3` 已經連通，因此這條邊形成環。

### 範例三：帳戶合併

不同帳戶若擁有相同 Email，就視為同一個人。使用 Email 將相關帳戶合併成群組。

## 16. 貪心

### 核心觀念

每一步做目前最有利的選擇，而且必須能證明這個選擇不會破壞全局最佳答案。

辨識訊號：活動選擇、最少區間、資源分配、每一步只需維護目前最佳狀態。

### 範例一：分配餅乾

```text
孩子需求：[1,2,3]
餅乾大小：[1,1]
輸出：1
```

使用最小但足夠的餅乾，優先滿足需求最小的孩子。

### 範例二：最多可以參加多少活動

給定多個 `[開始時間, 結束時間]`，選擇最多互不重疊的活動。按照結束時間排序，優先選擇最早結束的活動。

### 範例三：跳躍遊戲

```text
nums = [2,3,1,1,4]
輸出：true
```

遍歷時維護目前最遠可以到達的位置。

> 「看起來最好」不代表一定能用貪心；必須能證明局部選擇會導向全局最佳解。

## 17. 動態規劃

### 核心觀念

大問題可以拆成重複的小問題。先定義狀態並保存小問題答案，再組合成大問題答案。

學習 DP 時固定問四件事：

1. `dp[i]` 或 `dp[i][j]` 代表什麼？
2. 它從哪些以前的狀態得到？
3. 初始值是什麼？
4. 最後要回傳哪個狀態？

### 範例一：爬樓梯

```text
n = 4
輸出：5
```

狀態轉移：

```java
dp[i] = dp[i - 1] + dp[i - 2];
```

### 範例二：打家劫舍

```text
nums = [2,7,9,3,1]
輸出：12
```

相鄰房屋不能同時選擇。每一步比較「選目前房屋」和「不選目前房屋」。

### 範例三：零錢兌換

```text
coins = [1,2,5], amount = 11
輸出：3
```

答案是 `5 + 5 + 1`，求組成目標金額所需的最少硬幣數。

### 範例四：最長公共子序列

```text
text1 = "abcde"
text2 = "ace"
輸出：3
```

公共子序列是 `"ace"`，這是經典的二維 DP。

## 18. Trie

### 核心觀念

Trie 是專門保存字串的樹，多個字串可以共用相同前綴。

辨識訊號：字串前綴、自動補全、大量字典查詢、棋盤單字搜尋。

### 範例一：實作 Trie

```java
insert("apple");
search("apple");     // true
startsWith("app");   // true
```

### 範例二：搜尋建議

```text
輸入前綴："app"
輸出：apple、application、apply
```

### 範例三：棋盤單字搜尋

給定字母棋盤和大量單字，找出哪些單字可以在棋盤中形成。通常使用「Trie + DFS + 回溯」。

## 19. 位元運算

### 核心觀念

直接操作整數的二進位資料。

常見操作：

```java
a & b   // AND：兩邊都是 1 才是 1
a | b   // OR：有一邊是 1 就是 1
a ^ b   // XOR：兩邊不同才是 1
a << 1  // 左移
a >> 1  // 右移
```

### 範例一：只出現一次的數字

```text
nums = [4,1,2,1,2]
輸出：4
```

利用：

```text
x ^ x = 0
x ^ 0 = x
```

成對數字會互相抵消。

### 範例二：計算二進位中 1 的數量

```text
n = 11
二進位 = 1011
輸出：3
```

### 範例三：用位元表示子集合

```text
nums = [a,b,c]

000 → []
001 → [c]
010 → [b]
011 → [b,c]
...
111 → [a,b,c]
```

每一個 bit 表示對應元素是否被選擇。

## 核心觀念組合

一道題不一定只使用一個核心。Medium 和 Hard 題經常將多個觀念組合在一起。

| 題目 | 核心組合 |
| --- | --- |
| 最長總和為 K 的子陣列 | 前綴和 + HashMap |
| 滑動視窗最大值 | 滑動視窗 + 單調隊列 |
| 前 K 個高頻元素 | HashMap + Heap |
| 合併 K 個排序鏈表 | Heap + 鏈表 |
| 棋盤單字搜尋 | Trie + DFS + 回溯 |
| 不重疊區間 | 排序 + 貪心 |
| 課程依賴 | Graph + 拓撲排序 |
| 兩個排序陣列的中位數 | 二分搜尋 + 切割位置 |

難度通常可以這樣理解：

- **Easy**：直接使用一個核心觀念。
- **Medium**：一個核心的變形，或兩個核心組合。
- **Hard**：切入點較難、多個核心組合，或邊界情況複雜。

## 題型快速辨認表

| 題目特徵 | 優先考慮 |
| --- | --- |
| 查重、配對、統計次數 | HashMap / HashSet |
| 已排序陣列、兩數配對 | 雙指標 |
| 最長或最短連續區間 | 滑動視窗 |
| 連續區間總和且含負數 | 前綴和 |
| 已排序或答案有單調分界 | 二分搜尋 |
| 區間重疊 | 排序 |
| 括號、巢狀、撤銷 | Stack |
| 下一個更大或更小 | 單調棧 |
| 視窗最大或最小值 | 單調隊列 |
| 前 K 大或前 K 小 | Heap |
| 鏈表環或中點 | 快慢指標 |
| 所有組合或排列 | 回溯 |
| 樹的路徑或深度 | Tree DFS |
| 樹的層級 | Tree BFS |
| 圖的連通問題 | Graph DFS / BFS |
| 每一步距離相同的最短路徑 | BFS |
| 先後依賴 | 拓撲排序 |
| 動態合併群組 | 並查集 |
| 局部最佳且不必反悔 | 貪心 |
| 最值、方案數、重複子問題 | 動態規劃 |
| 字串前綴 | Trie |
| 二進位狀態、成對抵消 | 位元運算 |

## 建議練習順序

第一階段先掌握陣列和字串的基礎模型：

```text
HashMap
→ 雙指標
→ 滑動視窗
→ 前綴和
→ 二分搜尋
→ 排序與區間
→ Stack
```

第二階段學習結構遍歷與搜尋：

```text
Tree DFS / BFS
→ Graph DFS / BFS
→ 回溯
→ Heap
→ 拓撲排序
→ 並查集
```

第三階段學習最佳化與進階結構：

```text
貪心
→ 動態規劃
→ 單調棧／單調隊列
→ Trie
→ 位元運算
```

推薦的第一批練習題：

1. Two Sum
2. 判斷重複元素
3. 排序陣列 Two Sum
4. 判斷回文
5. 無重複字元的最長子字串
6. 固定長度子陣列最大總和
7. 最長總和為 K 的子陣列
8. 基本二分搜尋
9. 合併區間
10. 有效括號

第一遍的目標不是背模板，而是看到題目後能回答：

> 這題具有什麼特徵？哪個核心觀念最適合消除重複工作？
